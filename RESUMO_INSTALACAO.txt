🚀 COMO INSTALAR (3 PASSOS)
════════════════════════════════════════════════════════════════

PASSO 1: Clone e execute o script
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   git clone https://github.com/danielmedeiros22/task-manager-app.git
   cd task-manager-app
   chmod +x install-complete.sh
   ./install-complete.sh

PASSO 2: Configure Firebase (OBRIGATÓRIO)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. Abra o arquivo .env
   2. Preencha com suas credenciais do Firebase
   3. Copie google-services.json para android/app/
   4. Copie GoogleService-Info.plist para ios/TaskManager/

PASSO 3: Rode o app
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   Terminal 1:
      npm start

   Terminal 2:
      npm run android     # Android
      npm run ios         # iOS (macOS)

════════════════════════════════════════════════════════════════
⚙️ CONFIGURAR FIREBASE
════════════════════════════════════════════════════════════════

1. Acesse: https://console.firebase.google.com
2. Crie um novo projeto chamado "task-manager-app"
3. Ative: Authentication > Google
4. Crie: Realtime Database
5. Copie as credenciais para .env

Credenciais necessárias:
   • FIREBASE_API_KEY
   • FIREBASE_AUTH_DOMAIN
   • FIREBASE_DATABASE_URL
   • FIREBASE_PROJECT_ID
   • FIREBASE_STORAGE_BUCKET
   • FIREBASE_MESSAGING_SENDER_ID
   • FIREBASE_APP_ID

🆘 TROUBLESHOOTING
════════════════════════════════════════════════════════════════

"command not found: node"
→ Instale Node.js em https://nodejs.org/

"command not found: git"
→ Instale Git em https://git-scm.com/

"ANDROID_HOME not found"
→ export ANDROID_HOME=$HOME/Library/Android/sdk (macOS)
→ export ANDROID_HOME=$HOME/Android/Sdk (Linux)

"pod: command not found"
→ sudo gem install cocoapods

"Build failed"
→ npm run clean && npm start

"Metro timeout"
→ npm run clean:cache && npm start -- --reset-cache
